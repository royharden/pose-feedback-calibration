## Public contracts and scalar seam

`landmarks.Landmark(name, x, y, z, visibility, presence=None)` is frozen. Names are the33 standard named joints in `LANDMARK_NAMES`, in that exact order per pose. x/y are normalized image coordinates; z follows the source's normalized depth convention and is not used for2D knee geometry. Coordinates must be finite; out-of-frame coordinates may be outside[0,1]. Visibility and optional presence are separate bounded[0,1] fields. Missing presence stays null; zero presence makes a joint unusable, never silently becomes visibility.

`FrameBatch(t_media, poses, width, height, pixel_aspect=1.0, nominal_fps=30.0, source_id="fixture", source_kind="synthetic", status="ok", missing_slots=(), late_slots=(), receive_ns=None, clock_domain=None, clock_scope=None, model_id=None, runtime_id=None)` is frozen. A pose is an immutable tuple of33 Landmark objects; poses is a tuple with0..2 entries. No labels, names of people or split/gold truth fields exist. `source_kind` is synthetic/fixture/video/camera; status ok/missing/late; missing status cannot contain poses. Slot tuples carry distinct nonnegative nominal slot IDs no greater than the current floor-grid slot; late/missing status requires the current slot in the corresponding tuple; `.unavailable_slots` is their union, avoiding double counting. Nominal slot indexing starts at source media0 with floor(t*fps); declared missing/late slots do not alter event truth or synthesize samples.

`LandmarkSource` protocol exposes `read() -> FrameBatch | None` and `close()`. None means EOF, while unavailable/malformed/device failures raise `SourceError` with a sanitized `.reason`. This is an inference-only source boundary, not a study/admission or independent truth interface.

`StreamValidator.accept(batch, decoded_bytes=0)` owns one stream. It checks strictly increasing media time, minimum1/120s sample separation (with rounding tolerance), stable source/dimensions/aspect/fps/model/runtime/clock scope, receive monotonicity, <=60s media time, nominal<=120fps, <=2poses, <=7201samples and a128MiB decoded-trace budget. It adds a conservative per-frame/per-landmark/per-slot allowance to caller bytes, so caller row bytes and objects both consume budget. FrameBatch additionally bounds image dimensions to16384 and pixel aspect to100 as development resource guards. Failure latches; do not reuse a failed validator. Direct dataclass construction alone is not sequence validation; source readers and geometry enforce the stream validator.

Receive time, when supplied, is integer nanoseconds with `clock_domain="process_monotonic_ns"` and explicit UUID scope. It never replaces media time. Clock metadata is either fully absent or complete. Never subtract source media seconds from receive timestamps or subtract anchors from different scopes. Device media conventions and timestamp behavior require later operator/runtime verification.

## Geometry and movement producer

`GeometryAdapter.update(batch) -> tuple[GeometryFrame, ...]` buffers only media[0,3) warm-up and returns no outputs then. On the first frame at/after3, it fixes the higher mean hip/knee/ankle warm-up visibility side (ties left), median valid warm-up angle and median valid warm-up torso length, releases buffered frames IN ORDER, then the current frame. Scored frames never influence side/standing/torso references. `finish()` refuses a stream lacking complete warm-up selection. Adapter/source failure is terminal.

`GeometryFrame` is a frozen producer with fields `angle_frame, side, hip_xy, torso_length_px, missing_slots, late_slots, elbow_left, elbow_right, nominal_interval_s, slot_index, phase, evidence_reason, source_status, receive_ns, clock_domain, clock_scope`. Elbows are aspect-corrected shoulder/elbow/wrist angles in degrees, independently optional; missing/low-visibility/zero-presence joints stay unavailable. Phase is warmup/scored/tail, and receive clocks retain source metadata without media/host arithmetic. Consume `angle_frame` with the unchanged existing scalar `Counter.update`. There is no schema.py change or implicit CLI integration. `hip_xy` is the current midpoint of the hips in aspect-corrected pixels divided by the fixed warm-up median shoulder-midpoint-to-hip-midpoint torso length; null means unavailable. Feed scored, past/current samples only to a future movement consumer; the warm-up replay is for Counter's standing reference, not movement evidence at time>=3. `torso_length_px` is a fixed normalization reference, not a probability or form score. DL1 owns this producer; DL2 owns the FrameEvidence consumer. The r2 source seam uses the unchanged physical media time and floor-grid source slot. `nominal_interval_s` is1/fps only within[1/120,0.5] and `slot_index` remains the source floor slot, subject to the consumer's half-interval timestamp tolerance. Off-grid irregular samples return null interval/slot and `evidence_reason="nominal_grid_unavailable"`; time is never rounded, frames are never fabricated, and observations are never relabelled as future slots. Aligned original development frames can supply all required metadata. Missing hips/elbows give `movement_inputs_missing`; warmup replay is marked `warmup_not_scored`. `GeometryFrame.evidence_kwargs()` returns None for any of those reasons; otherwise it returns exactly elbow_left/elbow_right/hip_x/hip_y/torso_scale/nominal_interval_s/slot_index/missing_slots/late_slots for the consumer-owned constructor. Missing elbows must close the movement gate, not become perfect support. No consumer import or edit is introduced.

`knee_angle(batch, side)` uses aspect-corrected2D hip-knee-ankle vectors; unknown/missing/zero-length or low-visibility joints return null and nonfinite arithmetic raises a named error. Non-single-person input carries null angle and actual pose count; no identity is tracked. Missing poses never become a zero-degree angle or a successful zero count. Pixel aspect correction does not repair foreshortening. The scalar Counter still owns fixed[3,30) exposure, reset, eligible returns and tail confirmation; windows.py supplies boundary/nominal-slot helpers without labels or counter imports.
