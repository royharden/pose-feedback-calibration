## Proposed observation rules from the frozen plan

An observable squat cycle starts standing, descends and returns standing; depth is irrelevant. Count only cycles starting at or after3 seconds whose observed standing return occurs in [3,30). A cycle begun before3 seconds cannot finish a scored rep. Detector confirmation may use recorded post30-second tail, but it adds neither human truth returns nor negative exposure there. Use source media time rather than host/display clock. Preserve timestamps of observed returns without using detector output to place them.

Chair/object-context activities remain hard negatives under the scripted context; do not infer intent or change labels because a detector calls the motion a squat. Walking, waving and re-entry remain their original contexts. Unresolved visual ambiguity is unscoreable, not an invented zero. Actual humans must settle observation conventions/edge ambiguity before freezing, without relaxing the counting interval or depth-independent definition to fit detector results.
